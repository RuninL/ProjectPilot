## 用户操作路径

1. 打开“会议”，选择“创建周期会议”，填写“每周三 09:30”、项目、起止日期与议程模板并保存。
2. 打开“日历”，看到带“周期预期会议”文字的项目，并可从该项选择“物化本次”或“跳过本次”。
3. 物化后日历显示“已物化会议”，点击真实会议或色条可打开会议详情；“取消物化”会删除该真实会议并恢复预期项。
4. 跨日任务以横向色条显示，图例解释状态且不只依赖颜色。

## 尚存边界与技术债

- 周期规则仍只支持按周/隔周的单星期模式；不支持复杂 RRULE。
- 批量物化限定当前日历网格内的未来三次。
- React Router v7 major 升级仍作为阶段 A 已记录技术债。
